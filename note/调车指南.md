# 调车指南

> 调车 = 机器人 bring-up + PID 参数整定 + 功能验证。
> 先悬空调，再装车跑。安全第一。

## 一、调车前的硬件检查

- [ ] CAN 接口已 UP（`ip link show can0`）
- [ ] 串口设备存在（`ls /dev/IMU_*`）
- [ ] 所有电机 CAN ID 与代码配置一致
- [ ] DJI 电机电调已上电（24V）
- [ ] 无裁判系统时已注释断电保护
- [ ] `__DEBUG__` 已开启（CMakeLists.txt 已有）
- [ ] 遥控器已对频

## 二、安全机制

### ROBOT_NO_FORCE 模式

- 程序启动默认就是 `ROBOT_NO_FORCE`
- 此模式下**所有电机输出归零**（chassis、gimbal、shoot 全线）
- 如果调车时 PID 发散/暴走，任何位置设置：
```cpp
robot_set->set_mode(Types::ROBOT_MODE::ROBOT_NO_FORCE);
```

### 离线保护

- 电机 1000ms 无 CAN 反馈 → `offline()` 返回 true
- 日志输出 `"chassis_%d offline\n"` 表示对应电机离线
- `DEFAULT_OFFLINE_TIME = 1000` (ms)

### 裁判系统断电保护（调车时必须处理！）

`rc_controller.cc:34-46` —— 如果没接裁判系统，以下字段默认为 false：

```cpp
// 底盘电源状态 → false → 底盘不能动
mains_power_chassis_output

// 发射机构电源状态 → false → 不能射击
mains_power_shooter_output
```

**调车时如果没接裁判系统，需要注释掉 `rc_controller.cc:34-46` 这两段保护逻辑。**

### 摩擦轮斜坡启动

摩擦轮使用 `Ramp` 斜坡函数启动，防止电流冲击。不要直接给满电流。

## 四、遥控器操作

### 数据包结构（类型 types.hpp:43-58）

```cpp
struct ReceivePacket_RC_CTRL {
    int ch0, ch1, ch2, ch3, ch4;  // 5 个模拟通道 (范围 ~ ±660)
    int s1, s2;                    // 2 个三段开关 (1=UP, 2=DOWN, 3=MIDDLE)
    int mouse_x, mouse_y, mouse_z; // 鼠标轴
    int mouse_l, mouse_r;          // 鼠标按键
    int key;                       // 键盘按键位掩码
};
```

### 键盘按键映射（types.hpp:166-172）

| 宏 | 键 | 功能 |
|----|-----|------|
| `KEY_W` (0x8) | W | 前进 |
| `KEY_S` (0x4) | S | 后退 |
| `KEY_A` (0x2) | A | 左移 |
| `KEY_D` (0x1) | D | 右移 |
| `KEY_R` (0x40) | R | 切换自旋 |
| `KEY_F` (0x80) | F | 切换摩擦轮 |
| `KEY_PRESS` (0xff) | 任意键按下 | 切换到键盘模式 |

### 解锁组合键

```
S1 = DOWN  +  S2 = DOWN  +  CH4 滚轮 = 最上 (ROLL_UP_MAX=-660)
```

三个同时触发 → `inited = true`，从键盘模式切换到摇杆模式。

### 完整操控映射

| 操作 | 功能 | 条件 |
|------|------|------|
| W/A/S/D | 底盘平移 | 键盘模式 |
| R | 切换自旋 on/off | 键盘模式 |
| F | 切换摩擦轮 on/off | 键盘模式 |
| 鼠标移动 | 手动云台 yaw/pitch | 非自瞄模式 |
| 鼠标右键 | 开启自瞄 | — |
| S1_DOWN + S2_UP | 开启自瞄 | — |
| 鼠标左键 | 开火 (GIMBAL1) | — |
| CH0 | 云台 yaw (摇杆模式) | inited=true |
| CH1 | 云台 pitch (摇杆模式) | inited=true |
| CH2 | 底盘 vy 速度 | inited=true |
| CH3 | 底盘 vx 速度 | inited=true |
| S1=UP | wz=1.0 (自旋) | 摇杆模式 |
| S2=UP | 摩擦轮开 | 摇杆模式 |

## 五、调车流程（推荐顺序）

### 第 1 步：CAN 通信验证（单电机点动）

写临时测试代码，发 CAN 帧验证电机能转：

```cpp
can_frame frame = {};
frame.can_id = 0x200;  // M3508 1-4 号电机
frame.len = 8;
int16_t current = 1000;  // 小电流测试
memcpy(&frame.data[0], &current, 2);
can->send(frame);
```

✅ 电机微动 → CAN 通信 OK

### 第 2 步：IMU 通信验证

查看终端输出或 IMU 日志，确认 yaw/pitch 数据变化。

转动 IMU → 数据随之变化 → IMU 通信 OK

### 第 3 步：遥控器验证

开启 RC 日志（取消 rc_controller.cc 中 LOG_INFO 注释），确认按键/摇杆能收到数据。

### 第 4 步：底盘 PID 调参

#### 调参顺序：内环 → 外环

**内环 — 轮速环**（`chassis_config.wheel_speed_pid_config`）：

```cpp
// config_infantry.hpp:43-49
.wheel_speed_pid_config = {
    .kp = 15000, .ki = 10, .kd = 0,
    .max_out = 14000, .max_iout = 2000
};
```

- 固定机器人，轮子悬空
- kp 从小到大加 → 响应快但不振荡
- ki 加一点 → 消除稳态误差
- kd → 抑制超调

**外环 — 跟随云台环**（`chassis_config.chassis_follow_gimbal_pid_config`）：

```cpp
// config_infantry.hpp:36-42
.chassis_follow_gimbal_pid_config = {
    .kp = 2.0, .ki = 0, .kd = 10.0,
    .max_out = 6.0, .max_iout = 0.2
};
```

- 轮速环调好后，放地上调这个
- 这个环输入是角度差，输出是目标角速度

#### 控制参数

```cpp
.ControlTime = 2        // 底盘控制周期 2ms = 500Hz
.follow_dir = -1         // 步兵跟随方向
.CHASSIS_CONTROL_FREQUENCE = 500.0f
```

#### 麦轮逆运动学

```cpp
// chassis.cc
wheel_speed[0] = -vx - vy + wz;  // 左前
wheel_speed[1] = -vx + vy + wz;  // 右前
wheel_speed[2] =  vx - vy + wz;  // 左后
wheel_speed[3] =  vx + vy + wz;  // 右后
```

### 第 5 步：云台 PID 调参

云台使用**串级 PID**（位置环 + 速度环），先内后外。

#### 内环 — 速度环

```cpp
// yaw 速度 (config_infantry.hpp:61-67)
.yaw_rate_pid_config = {
    .kp = 16668, .ki = 234, .kd = 200,
    .max_out = 30000, .max_iout = 15000
};

// pitch 速度 (config_infantry.hpp:69-75)
.pitch_rate_pid_config = {
    .kp = 9073, .ki = 283, .kd = 0,
    .max_out = 30000, .max_iout = 15000
};
```

#### 外环 — 位置环

```cpp
// yaw 绝对位置 (config_infantry.hpp:94-100)
.yaw_absolute_pid_config = {
    .kp = 8.0, .ki = 0.062, .kd = 0,
    .max_out = 60, .max_iout = 0
};

// pitch 绝对位置 (config_infantry.hpp:102-108)
.pitch_absolute_pid_config = {
    .kp = 13.45, .ki = 0, .kd = 0,
    .max_out = 10, .max_iout = 0
};
```

#### 关键配置

```cpp
.ControlTime = 1          // 云台控制周期 1ms = 1000Hz
.gimbal_motor_dir = 1.0   // 电机方向
.YawOffSet = 5217          // yaw 编码器零点偏移
```

#### 初始化参数

```cpp
.GIMBAL_INIT_STOP_TIME = 2000   // 回中稳定时间 2s
.GIMBAL_INIT_EXP = 0.1f         // 稳定判定阈值 0.1 rad
```

### 第 6 步：发射机构调参

```cpp
// 摩擦轮 PID (config_infantry.hpp:117-123)
.friction_speed_pid_config = {
    .kp = 8000, .ki = 0.05, .kd = 18,
    .max_out = 16000, .max_iout = 2000
};

// 拨弹 PID (config_infantry.hpp:124-130)
.trigger_speed_pid_config = {
    .kp = 5000, .ki = 2, .kd = 0,
    .max_out = 10000, .max_iout = 9000
};

// 摩擦轮速度
.FRICTION_MAX_SPEED = 2.5f      // 摩擦轮最大线速度 2.5 m/s
```

#### 卡弹检测

- 拨弹电机电流 > 4000 且转速 < 1 → 判定卡弹
- 停止拨弹 50ms 后重试

## 六、PID 调参口诀

| 参数 | 增大后的效果 | 什么时候加 |
|------|-------------|-----------|
| **kp** | 响应更快，过大振荡 | 响应太慢 |
| **ki** | 消除稳态误差，过大超调 | 有稳态误差 |
| **kd** | 抑制超调，过大抖振 | 振荡/超调大 |

### 调试方法

1. **悬空调内环**：给目标速度，看实际速度能否跟上
2. **放地调外环**：底盘/云台有负载后，外环参数需要重新调
3. **先 P 后 I 最后 D**：先只调 kp，加上 ki 消静差，有振荡再加 kd
4. **max_out 限幅**：先设小值（如 5000）保护电机，调好后再放大

## 七、常见问题排查

| 现象 | 可能原因 | 检查方法 |
|------|---------|---------|
| 所有电机不动 | CAN 未 UP | `ip link show can0` |
| 某个电机不动 | CAN ID 不匹配 | 核对 config 中 `DJIMotorConfig{型号, "canX", ID}` |
| 底盘不能动 | 裁判断电保护 | 注释 rc_controller.cc:34-38 |
| 不能射击 | 裁判断电保护 | 注释 rc_controller.cc:40-46 |
| 云台不初始化 | IMU 未上线 | 看终端 `"status: imu_yaw:off"` |
| 电机抖动/异响 | PID 增益过大 | 先减 kp，再加 kd |
| 电机无力 | PID 增益过小 或 max_out 太小 | 增大 kp / max_out |
| 遥控器无响应 | 未解锁 | S1_DOWN + S2_DOWN + CH4_UP |
| 云台不跟鼠标 | 自瞄模式开启 | 关自瞄 (鼠标右键 / S1+S2) |
| 摩擦轮不转 | friction_open = false | 按 F 或 S2_UP 开启 |
| "chassis_X offline" | 电机 CAN 断连 | 检查对应电机接线 |
