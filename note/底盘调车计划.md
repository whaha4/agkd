# 底盘调车计划（仅底盘 · 无云台/IMU/遥控器）

> 状态：准备执行 | 目标：四麦轮底盘通过 SSH 键盘可控运动

---

## 方案选择：为什么用 ControlLib 而不是 GKD_Control

| | GKD_Control | ControlLib |
|---|---|---|
| 依赖 | 云台、IMU、裁判系统、遥控器、超级电容 | **只有 CAN + 电机** |
| 代码量 | 20+ 个模块互相耦合 | 单文件即可 |
| 启动流程 | load_hardware → start_init(云台回中) → start | 直接跑 |
| 构建 | CMake + 第三方串口库 | CMake，无需外部库 |

**结论：直接用 ControlLib 写一个底盘测试程序。** 不改 GKD_Control 任何代码，等完整机器人装好后再用 GKD_Control。

## 第三步：电机逐个验证（方向确认）

程序启动后电机不会自动转，按键盘才会发指令。先逐个确认电机 ID 和转向：

### 3.1 ID 对应

```
俯视图（从上看）：

      前方 →
   ┌──────────┐
   │ M1   M2  │    M1 = CAN ID 1 = 左前轮
   │   (车体)  │    M2 = CAN ID 2 = 右前轮
   │ M3   M4  │    M3 = CAN ID 3 = 左后轮
   └──────────┘    M4 = CAN ID 4 = 右后轮
```

### 3.2 验证方法

用手抬起车，使轮子悬空。给单个电机发小电流，看哪个轮子转。

可以在代码中临时加上单电机测试代码（或直接修改 `give_current`）：

```cpp
// 临时测试：只给电机1发电流
motors[0].give_current = 1000;  // 左前轮应该转
motors[1].give_current = 0;
motors[2].give_current = 0;     
motors[3].give_current = 0;
```

### 3.3 方向检查

四个电机给**正电流**，输出轴应该**逆时针**转（从轴端看）。

对麦轮 X 型布局（最常见的布局）：

```
左前(M1): 逆时针 → 轮子向前滚（正确）
右前(M2): 逆时针 → 轮子向前滚（正确）
左后(M3): 逆时针 → 轮子向前滚（正确）
右后(M4): 逆时针 → 轮子向前滚（正确）
```

**如果某个轮子方向反了**：在代码中该电机的 set 值取负号。

> 从 `candump` 确认：转速字段 `speed_rpm` 正值=逆时针（从轴输出端看）。

## 第四阶段：麦轮运动学方向验证

四个轮子放下到地面，用键盘发送运动指令验证：

| 按键 | vx | vy | wz | 期望运动 |
|------|-----|-----|-----|----------|
| W | +0.5 | 0 | 0 | 车向前走 |
| S | -0.5 | 0 | 0 | 车向后退 |
| A | 0 | +0.5 | 0 | 车向左平移 |
| D | 0 | -0.5 | 0 | 车向右平移 |
| Q | 0 | 0 | +1.0 | 逆时针旋转 |
| E | 0 | 0 | -1.0 | 顺时针旋转 |
| 空格 | 0 | 0 | 0 | 急停 |

**运动方向不对的排查流程**：

1. **前进变后退**：四个电机的 PID set 整体取负
2. **左移变右移**：vy 符号取反
3. **旋转方向反**：wz 符号取反
4. **平移时车在旋转**：某个轮子 ID 线序错了或麦轮装错了方向

> 麦轮装错（左旋轮装到右旋位置）会导致平移时车打转，需要物理重装。

## 第五阶段：速度闭环 PID 调参

### 5.1 当前 PID 参数（来自 GKD_Control）

| 参数 | 值 | 说明 |
|------|-----|------|
| KP | 15000 | 比例项 |
| KI | 10 | 积分项 |
| KD | 0 | 微分项 |
| max_out | 14000 | 最大输出(mA) |
| max_iout | 2000 | 最大积分输出 |

- 3508 电机最大持续电流 ≈ 10000mA
- PID 输出上限 14000 略高（峰值电流 OK），调车时先降到 8000
- KI=10 非常小，先调 KP

### 5.2 调 KP（KD=0, KI=0）

给阶跃指令（W 键 0.5 m/s），观察：

| KP | 现象 | 处理 |
|------|------|------|
| 5000 | 响应慢，达不到目标速度 | 加倍 |
| 10000 | 响应中等 | 继续加 |
| 15000 | 响应快，接近目标 | 观察超调 |
| 20000+ | 有异响/震动/超调 | 退回上一个值 |

**目标**：阶跃响应快（<0.2s 达目标）、无明显超调、无啸叫。

### 5.3 调 KI

- KP 定下来后，从 KI=50 开始加
- 每次加 50，直到稳态速度误差 < 5%
- 观察积分饱和：长时间按住 W 后松开，车不应继续往前冲
- 如果震荡 → 减小 KI 或增大 max_iout

### 5.4 调 KD（可选）

- 如果速度阶跃有震荡/overshoot，加入 KD=500~2000
- KD 太大会引入高频噪音（电机滋滋响）

### 5.5 调参日志方法

在代码中打印每个轮子的目标速度和实际速度：

```cpp
printf("W0: set=%.2f real=%.2f | W1: set=%.2f real=%.2f | "
       "W2: set=%.2f real=%.2f | W3: set=%.2f real=%.2f\n",
       wheel_speed[0], motors[0].data_.output_linear_velocity,
       wheel_speed[1], motors[1].data_.output_linear_velocity,
       wheel_speed[2], motors[2].data_.output_linear_velocity,
       wheel_speed[3], motors[3].data_.output_linear_velocity);
```

## 第六阶段：实车跑

PID 调好后，让车在平地上走：

### 测试项目

1. **直线前进/后退 2 米**：看是否跑偏
2. **左右平移 1 米**：看是否旋转
3. **原地旋转 90°/180°**：看角度是否准确
4. **正方形路径**：前进→左移→后退→右移，看是否回到原点

### 如果跑偏

- 四个轮子直径有微小差异 → 给每个轮子加一个补偿系数
- 地板不平/摩擦力不均 → 正常的，嵌入式层面很难完全消除，视觉/IMU 才能修正

## 附录 A：chassis_test.cpp 完整代码

> 在 mini PC 上创建 `~/chassis_tune/chassis_test.cpp`：

```cpp
#include <atomic>
#include <cmath>
#include <cstdio>
#include <csignal>
#include <termios.h>
#include <fcntl.h>
#include <unistd.h>
#include <chrono>
#include <algorithm>

#include "dji_motor.hpp"
#include "io.hpp"
#include "pid.hpp"

// ====== 配置 ======
constexpr const char* CAN_NAME    = "CAN_CHASSIS";
constexpr float WHEEL_RADIUS      = 0.075f;     // 轮子半径 (m)
constexpr float REDUCTION_RATIO   = 1.0f / 19.0f; // M3508 减速比
constexpr float MAX_WHEEL_SPEED   = 2.5f;       // 单轮最大线速度
constexpr float CMD_SPEED         = 0.5f;       // 默认指令速度
constexpr float CMD_ROTATE        = 1.0f;       // 默认旋转速度
constexpr int   CONTROL_PERIOD_MS = 2;          // 控制周期 2ms = 500Hz

// ====== PID 参数 ======
constexpr Pid::PidConfig WHEEL_PID = {
    .kp       = 15000.0f,
    .ki       = 10.0f,
    .kd       = 0.0f,
    .max_out  = 8000.0f,   // 调车先限到8000
    .max_iout = 2000.0f,
};

// ====== 急停标志 ======
std::atomic<bool> running(true);

void signal_handler(int) {
    running = false;
    printf("\n[!] 急停信号\n");
}

// ====== 非阻塞键盘读取 ======
int kbhit() {
    struct termios oldt, newt;
    int ch, oldf;
    tcgetattr(STDIN_FILENO, &oldt);
    newt = oldt;
    newt.c_lflag &= ~(ICANON | ECHO);
    tcsetattr(STDIN_FILENO, TCSANOW, &newt);
    oldf = fcntl(STDIN_FILENO, F_GETFL, 0);
    fcntl(STDIN_FILENO, F_SETFL, oldf | O_NONBLOCK);
    ch = getchar();
    tcsetattr(STDIN_FILENO, TCSANOW, &oldt);
    fcntl(STDIN_FILENO, F_SETFL, oldf);
    return (ch != EOF) ? ch : 0;
}

// ====== 主函数 ======
int main() {
    signal(SIGINT, signal_handler);
    signal(SIGTERM, signal_handler);

    // --- 初始化 CAN ---
    IO::io<CAN>.insert(CAN_NAME);
    printf("[init] CAN %s opened\n", CAN_NAME);

    // --- 创建 4 个 M3508 电机 ---
    Hardware::DJIMotor motors[4] = {
        Hardware::DJIMotor(3508, CAN_NAME, 1, WHEEL_RADIUS),
        Hardware::DJIMotor(3508, CAN_NAME, 2, WHEEL_RADIUS),
        Hardware::DJIMotor(3508, CAN_NAME, 3, WHEEL_RADIUS),
        Hardware::DJIMotor(3508, CAN_NAME, 4, WHEEL_RADIUS),
    };

    for (auto& m : motors) m.enable();
    Hardware::DJIMotorManager::start();
    printf("[init] 4 motors registered\n");

    // --- 创建 4 个速度 PID ---
    Pid::PidPosition wheel_pid[4] = {
        Pid::PidPosition(WHEEL_PID, motors[0].data_.output_linear_velocity),
        Pid::PidPosition(WHEEL_PID, motors[1].data_.output_linear_velocity),
        Pid::PidPosition(WHEEL_PID, motors[2].data_.output_linear_velocity),
        Pid::PidPosition(WHEEL_PID, motors[3].data_.output_linear_velocity),
    };

    // --- 控制变量 ---
    float vx_target = 0.f, vy_target = 0.f, wz_target = 0.f;
    float wheel_speed[4] = {0};

    printf("\n========================================\n");
    printf("  底盘调车程序\n");
    printf("  W/S: 前进/后退    A/D: 左移/右移\n");
    printf("  Q/E: 逆时针/顺时针旋转\n");
    printf("  空格: 急停        ESC: 退出\n");
    printf("  1/2: 加速/减速    R: 重置 PID\n");
    printf("========================================\n\n");

    float speed_step = 0.1f;
    auto last_print = std::chrono::steady_clock::now();

    while (running) {
        // --- 键盘输入 ---
        int key = kbhit();
        switch (key) {
            case 'w': case 'W': vx_target += speed_step; break;
            case 's': case 'S': vx_target -= speed_step; break;
            case 'a': case 'A': vy_target += speed_step; break;
            case 'd': case 'D': vy_target -= speed_step; break;
            case 'q': case 'Q': wz_target += 0.2f;      break;
            case 'e': case 'E': wz_target -= 0.2f;      break;
            case ' ':  vx_target = vy_target = wz_target = 0.f; break;
            case '1':  speed_step = std::min(speed_step + 0.05f, 2.0f); 
                       printf("speed step: %.2f\n", speed_step); break;
            case '2':  speed_step = std::max(speed_step - 0.05f, 0.05f);
                       printf("speed step: %.2f\n", speed_step); break;
            case 'r': case 'R':
                for (auto& p : wheel_pid) p.clean();
                vx_target = vy_target = wz_target = 0.f;
                printf("[reset] PID cleared\n");
                break;
            case 27:   running = false; break; // ESC
        }

        // --- 限幅 ---
        vx_target = std::clamp(vx_target, -3.0f, 3.0f);
        vy_target = std::clamp(vy_target, -3.0f, 3.0f);
        wz_target = std::clamp(wz_target, -5.0f, 5.0f);

        // --- 麦轮逆解：车身坐标系 → 四轮速度 ---
        // 左前(-), 右前(-), 左后(+), 右后(+)
        wheel_speed[0] = -vx_target - vy_target + wz_target; // M1 左前
        wheel_speed[1] = -vx_target + vy_target + wz_target; // M2 右前
        wheel_speed[2] =  vx_target - vy_target + wz_target; // M3 左后
        wheel_speed[3] =  vx_target + vy_target + wz_target; // M4 右后

        // --- 限幅单轮速度 ---
        float max_ws = 0.f;
        for (int i = 0; i < 4; i++)
            max_ws = std::max(max_ws, fabsf(wheel_speed[i]));
        if (max_ws > MAX_WHEEL_SPEED) {
            float ratio = MAX_WHEEL_SPEED / max_ws;
            for (int i = 0; i < 4; i++) wheel_speed[i] *= ratio;
        }

        // --- PID 控制 ---
        for (int i = 0; i < 4; i++) {
            wheel_pid[i].set(wheel_speed[i]);
            motors[i].give_current = static_cast<int16_t>(wheel_pid[i].out);
        }

        // --- 状态打印 (10Hz) ---
        auto now = std::chrono::steady_clock::now();
        if (now - last_print > std::chrono::milliseconds(100)) {
            last_print = now;
            printf("\r[%.1f,%.1f,%.1f] W:[%5.2f %5.2f %5.2f %5.2f] real:[%5.2f %5.2f %5.2f %5.2f] cur:[%4d %4d %4d %4d]",
                   vx_target, vy_target, wz_target,
                   wheel_speed[0], wheel_speed[1], wheel_speed[2], wheel_speed[3],
                   motors[0].data_.output_linear_velocity,
                   motors[1].data_.output_linear_velocity,
                   motors[2].data_.output_linear_velocity,
                   motors[3].data_.output_linear_velocity,
                   motors[0].give_current, motors[1].give_current,
                   motors[2].give_current, motors[3].give_current);
            fflush(stdout);
        }

        UserLib::sleep_ms(CONTROL_PERIOD_MS);
    }

    // --- 停止所有电机 ---
    printf("\n[exit] 停止所有电机...\n");
    for (auto& m : motors) m.give_current = 0;
    UserLib::sleep_ms(50);
    printf("[exit] 安全退出\n");
    return 0;
}
```
